# Local Image Search Engine

ローカル環境で動作するAI画像解析・検索アプリケーションです。
指定したフォルダ内の画像をAIが自動解析してタグ付けや絵柄抽出を行い、ベクトル検索と独自のスコアリングにより、タグだけでなく、日本語や直感的なワード、あるいは「好みの絵柄」で目的の画像を探し出すことができます。

## 主な特徴

* **AIタグ付け**: イラストの局所的特徴の抽出に特化した2つのモデル（ConvNeXt, MOAT）によるアンサンブル推論で、高精度なタグ付けを実行します。これにより、イラストの特徴で検索することができます。
* **絵柄検索**: VGG16モデルを用いたAdaINの統計量（平均・標準偏差）抽出により、画像が持つ「画風・絵柄」をベクトル化します。好みの画像を複数枚選択して「重心ベクトル」を計算することで、言語化が難しい「自分好みの絵柄」をオリジナルタグとして保存し、直感的に検索することが可能です。
* **セマンティック検索**: 「10万語規模の翻訳辞書」と「CLIPモデルによるベクトル検索」を組み合わせることで、あいまいな表現でも目的の画像をヒットさせます。
* **独自スコアリング**: 検索ワードとの「類似度」× AIの「確信度」× タグの「希少度(IDF)」を掛け合わせ、最適な順序で結果を表示します。
* **モダンWeb UI**: フロントエンドを Next.js (React) と Tailwind CSS を用いて、モダンなWebアプリケーションを実現。クロスデバイスでの利用を前提とした柔軟なUIコンポーネント設計と、複雑な状態管理をスマートに統合しています。

## 環境構築

### 1. Python仮想環境の作成とライブラリのインストール
プロジェクトルートでPython仮想環境（`.venv`、Python 3.10以上推奨）を作成し、必要なパッケージをインストールしてください。

```bash
python -m venv .venv
.venv\Scripts\activate

pip install -r requirements.txt
# または個別にインストールする場合:
pip install fastapi uvicorn python-dotenv requests opencv-python pandas numpy faiss-cpu
pip install torch torch-directml torchvision
pip install onnxruntime-directml huggingface-hub transformers
pip install translators pillow
```

### 2. 環境設定 (.envの作成) とフロントエンドのビルド

プロジェクトのルートディレクトリに `.env` ファイルを作成し、通信用のポート番号とIPアドレスを設定します。

```ini
API_PORT=8715
API_HOST=127.0.0.1
```
※ `API_HOST` にはお使いのPCのIPアドレス（または `127.0.0.1`）を指定してください。

続いて、`frontend` ディレクトリで依存パッケージのインストールと本番ビルドを実行します（設定を変更した場合も必ず `npm run build` を再実行してください）。

```bash
cd frontend
npm install
npm run build
cd ..
```

### 3. ディレクトリ構成

実行前に、画像を入れるためのフォルダを準備します。デフォルトでは `data/images` フォルダ直下、およびサブフォルダをスキャン対象とします。事前にフォルダを作成し、検索したい画像を配置してください。


## 使い方 (初期セットアップ・画像追加)

### Step 0: 画像の整理と重複排除 (任意)

iPhoneなどから取り込んだ雑多な画像群を、撮影年月（YYYYMM）ごとのフォルダに自動で振り分け、ファイル名を「撮影日時_ハッシュ値」にリネームして整理します。これにより、物理的な画像の重複を完全に排除し、将来的なマージも容易になります。

**💡 安全なコピー処理**
このスクリプトは元の画像（`data/images/` など）を移動するのではなく、新しいフォルダ（`data/sorted/` など）へ「コピー」する仕様になっています。そのため、数万枚の処理中に万が一エラーで中断されたりPCの電源が落ちたりしても、**元のデータが消えたり破損したりする心配はありません。**
また、再実行した際もハッシュ値によって既にコピー済みの画像は自動でスキップされるため、安心して続きから再開できます。

※実行前に `scripts/sort.py` 内の `SOURCE_DIR`（元の画像場所）と `TARGET_DIR`（整理後の保存先）が、自身の環境（`data/images` など）を指しているか確認してください。

```bash
python -m scripts.sort
```

### 🚀 初回の一括セットアップ (`setup.bat` の実行)

`data/images` に画像を配置したら、プロジェクトルートにある **`setup.bat`** を実行（またはダブルクリック）するだけで、以下の **Step 1 〜 Step 5** がすべて自動で実行されます（初回のみネット接続が必要です）。

```bash
.\setup.bat
```

**⚡ CPU / GPU 並列パイプライン**
`setup.bat` は最初に新規画像のファイルスキャンとDB初期化（`tasks.index --scan-only`）を完了させた後、自動的に2つのウィンドウに分かれて並列処理を行います。
- **CPUウィンドウ**: 翻訳辞書のダウンロード（Step 1） → サムネイル生成（Step 3後半）
- **GPUウィンドウ**: タグリストのベクトル化（Step 2） → AIタグ付け（Step 4） → 絵柄ベクトル生成（Step 5）

---

### 🔄 普段の画像追加・更新 (`tasks/update_images.bat` の実行)

2回目以降に `data/images` へ新しい画像を追加した際は、**`tasks/update_images.bat`** を実行（またはダブルクリック）してください。
初回専用の辞書ダウンロード等を省き、追加された画像に対する **DB登録 → サムネイル生成（CPU）＆ AIタグ付け・絵柄ベクトル化（GPU）** を別ウィンドウで並列実行します。

```bash
.\tasks\update_images.bat
```

### 個別スクリプトの詳細 (手動で順番に実行する場合)

バッチファイルを使わず、各ステップを個別に実行したい場合は以下のコマンドを使用します。

#### Step 1: 辞書のダウンロード

10万語規模の英日翻訳辞書を取得します。（初回のみネット接続が必要です）

```bash
python -m scripts.download_assets
```

#### Step 2: タグリストのベクトル化

AIの出力タグを意味のベクトルに変換し、検索用のインデックスを作成します。（初回のみネット接続が必要です）

```bash
python -m scripts.vectorize_tags
```

#### Step 3: 画像のスキャンとサムネイル生成

`data/images` フォルダ内の画像をデータベースに登録し、表示用の軽いサムネイルを作成します。（`--scan-only` でDB登録のみ、`--thumb-only` でサムネイル生成のみを実行することも可能です）

```bash
python -m tasks.index
```

#### Step 4: AIによる画像解析（タグ付け）

データベースに登録された画像に対して、AIが自動で内容を判別しタグを付与します。
*(※ 枚数が多い場合は時間がかかります。DirectMLによるGPU支援が効いているかターミナルで確認してください)*

```bash
python -m tasks.tagger
```

#### Step 5: 絵柄ベクトルの生成

VGG16モデルを使用して、全画像から画風（平均・標準偏差）を抽出し、検索用のFAISSインデックスを作成します。

```bash
python -m tasks.vectorize_images
```

## アプリの起動と操作

すべての準備が整ったら、`start_local-image-search-engine.vbs` をダブルクリックしてアプリを起動します。（コマンドプロンプトはバックグラウンドで隠れます）

- **起動時のデフォルト（軽量モード）**: 起動時は重い機械学習ライブラリ（PyTorch / DirectML / FAISS）をロードせず、省メモリ・高速（約1〜2秒）で立ち上がります。通常のタグ検索やキャッシュ済みの絵柄検索をサクサク行えます。
- **重量モードへの切り替え（フロントエンドから操作）**: 画面右上の **`軽量版`** ボタンを押すと、バックグラウンドでAI推論用子プロセス（CLIP・VGG16・FAISS）が起動し **`重量版 ON`** に切り替わります。未知語のAI翻訳＋ベクトル検索や、新しい絵柄タグの作成が可能になります。使い終わったら再度ボタンを押すことで子プロセスが終了し、確保していたRAM・VRAMがOSへ100%解放されて軽量モードに戻ります。

起動後、ブラウザで `.env` に設定したIPアドレスとポート（例: `http://localhost:3715` や `http://192.168.1.xxx:3715`）にアクセスするとUIが表示されます。

### PC起動時の自動起動（常駐化）

毎回手動で起動する手間を省き、PCを立ち上げた時に自動でサーバーを裏側で起動させておくことができます。

1. キーボードの `Windowsキー + R` を同時に押し、「ファイル名を指定して実行」ウィンドウを開きます。
2. 名前の欄に `shell:startup` と入力して「OK」を押すと、Windowsの「スタートアップ」フォルダが開きます。
3. このプロジェクトフォルダ内にある `start_local-image-search-engine.vbs` を **右クリック** して **「ショートカットの作成」** を選びます。
4. 作成されたショートカットファイルを、先ほど開いた「スタートアップ」フォルダの中に移動（またはコピー）します。

これだけで、次回PCを起動した時から自動的にバックグラウンドでサーバーが立ち上がり、いつでもブラウザから即座に検索エンジンにアクセスできるようになります。

### 基本操作

* **検索窓**: 日本語、英語、俗語など好きな言葉を入力してEnterを押します。スペース区切りで **AND検索**、`|` 区切りで **OR検索**、先頭に `-`（ハイフン）を付けることで**除外検索（マイナス検索）**が可能です。検索窓を空欄にして検索すると全件表示になります。
* **絵柄検索**: `style:作成した絵柄名` を入力すると、その画風に近い画像で絞り込めます。タグ検索と併用可能です（例: `style:my_favorite 黒髪`）。
* **サジェスト**: 文字を入力すると、DB内に存在するタグや辞書のヒット件数がサジェスト表示されます。絵柄名（`style:`）のサジェストおよびサジェスト枠からの絵柄タグ削除にも対応しています。
* **お気に入り・ゴミ箱フィルター**: 検索窓右側のハートボタンでお気に入り登録済み画像のみの絞り込み、ゴミ箱ボタンで論理削除済み（`data/trash/`）画像の一覧表示を切り替えられます。
* **ブックマーク**: 検索窓のブックマークアイコンから、現在の検索条件に名前を付けて保存できます。画面左端からの右スワイプ（またはメニューボタン）でドロワーを開き、保存した条件をすぐに呼び出せます。
* **ギャラリー（グリッド操作）**:
  * **列数の変更**: スマホでは**ピンチイン・ピンチアウト**（1〜8列）、PCでは **Shift + マウスホイール**（2〜12列）で直感的に画像の列数を変更できます。
  * **グリッドの再読み込み**: 画面最上部でさらに下へ引っ張るスワイプ操作（**プルリフレッシュ**）、またはPCの **`r` キー**で、現在の検索条件・ソート順（ランダム含む）を維持したままグリッドを再読み込みできます。
  * **一番上に戻るボタン**: 下へスクロールした状態から上方向へスクロール（スワイプ）した時のみ右下に表示され、タップすると先頭へ戻ります。
* **下部コントロールバー**:
  * **選択モード**: 複数枚の画像を選択し、アクションメニューから「**絵柄タグを作成**」や「**ゴミ箱へ移動**」（ゴミ箱表示中は「**元の場所へ復元**」）を一括実行できます。
    * ※ お気に入り（いいね）登録済みの画像が選択に含まれている場合は、誤削除防止のため「ゴミ箱へ移動」ボタンがグレーアウトして無効化されます。
  * **ソート順切り替え**: 「スコア順」⇔「新着順」を切り替えます。直前にビューアーで閲覧していた画像がある場合、その画像を画面中央に維持したまま並び替えます。
  * **ランダム表示**: 現在の検索条件・フィルターを維持したまま、並び順をランダムにシャッフルします。

### ビューア操作 (画像クリック時)

* **UI表示の切り替え**: 画像または余白をシングルタップ（クリック）すると、周囲のボタンや日付表示のON/OFFを切り替えられます。
* **上部ステータス・削除/復元**:
  * **保存日付表示**: 上部中央に画像の保存日付（`YYYY.MM.DD` 形式）が表示されます。
  * **ゴミ箱へ移動 / 復元**: 左上のボタンから画像を論理削除（`data/trash/` へ移動）し、自動で前後の画像へ切り替えます（ゴミ箱表示中は元の場所へ復元）。
    * ※ お気に入り登録済みの画像はゴミ箱ボタンがグレーアウトし、ゴミ箱へ移動できないよう保護されます。
* **下部アクション**:
  * **お気に入り（いいね）**: 左下のハートボタンでお気に入り登録・解除を切り替えられます。
  * **類似画像検索**: 右下の「類似画像」ボタンから、表示中の画像の髪色・目の色タグを自動抽出して類似キャラを検索できます。
* **ズーム・パン操作**:
  * **スマホ**: **ピンチイン・ピンチアウト**で自由な倍率（最大5倍）での拡大・縮小と、1本指ドラッグによる移動が可能です。
  * **PC**: **ダブルクリック**で2倍ズームモードに入り（再度ダブルクリックで等倍へ復帰）、ズーム中は**マウスホイール**で倍率変更、**ドラッグ**で移動できます。
* **スワイプ / キーボード操作**:
  * **左右スワイプ / `←` `→` キー**: 前後の画像へ移動します（ビューアーを閉じた際、グリッド側も最後に見ていた画像の座標へ自動でスクロール追従します）。
  * **上スワイプ / `↑` キー**: 画面下部から「ファイル名」「ファイルパス」「付与されたタグ一覧」の詳細パネルを引き出します。
  * **下スワイプ / `↓` キー / `Esc` キー**: 詳細パネルが開いている場合はパネルを閉じ、閉じている場合はビューアー自体を閉じます。
